Gambar 4.5 Sketsa Hi-Fi Modal Langkah Matematis KNN Ukuran Screen: 1280 × 720px
PERHITUNGAN KNN

Langkah Matematis Rekomendasi

d(x, y) = √((MTKx - MTKy)² + (IPAx - IPAy)² + (IPSx - IPSy)² + (BINDOx - BINDOy)² + (PJOKx - PJOKy)² + (SBPx - SBPy)²)
Rincian Hitung
X = (MTKuj, IPAuj, IPSuj, BINDOuj, PJOKuj, SBPuj)
Y = (MTKlath, IPAlath, IPSlath, BINDOlath, PJOKlath, SBPlath)

d₁ = (MTKx - MTKy)²
d₂ = (IPAx - IPAy)²
d₃ = (IPSx - IPSy)²
d₄ = (BINDOx - BINDOy)²
d₅ = (PJOKx - PJOKy)²
d₆ = (SBPx - SBPy)²

d(x, y) = √(d₁ + d₂ + d₃ + d₄ + d₅ + d₆)
Hasil jarak ini digunakan untuk urutan tetangga terdekat.
